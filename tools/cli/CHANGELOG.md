# Changelog

All notable changes to `@0x-copilot/cli`.

Generated by `.github/workflows/release-cli.yml` from Conventional Commits.
While the package is 0.x, a breaking change bumps the MINOR digit and
everything else bumps PATCH -- npm treats `^0.1.4` as `>=0.1.4 <0.2.0`.

## 0.1.4 - 2026-07-31

Baseline. Versions up to and including 0.1.4 were published by hand, before
`release-cli.yml` existed, so there is no per-release history to reconstruct
for them.

The `cli-v0.1.4` tag marks this point. Everything after it is what the first
automated release will describe -- without that tag the generator sees no
previous release and sweeps the entire repository history (~1,490 commits)
into one entry.

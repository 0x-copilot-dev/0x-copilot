# Sub-module symbols that are built but not wired — the burn-down list for
# tools/check_dark_wiring.py.
#
# Every line is a symbol that reached production with its last seam missing:
# reachable by no product caller, populated by no producer, or enforced by
# nothing but a sentence handed to a model. They predate the gate. This file is
# DEBT, not approval.
#
# There is deliberately no `--update-baseline` writer, for the reason
# route_reachability_baseline.txt has none: the only sanctioned way to add a line
# is to write the reason by hand, where a reviewer reads it in the diff. Wiring a
# symbol to a real consumer makes its line here stale, and a stale line FAILS the
# gate — so this file can only ever shrink.
#
# Format: <ratchet key> :: <why it is here>
#
# A line is legitimate for exactly two reasons: (a) the symbol is genuinely dark
# and is being kept deliberately, or (b) it IS reached, by a consumer this static
# scan cannot see — an unresolvable receiver, a dynamically assembled attribute,
# a TypeScript destructure. Say which. The gate is biased toward silence, so (b)
# should be rare; when it happens it is a fact about the scan's blind spots and
# is worth recording as one.

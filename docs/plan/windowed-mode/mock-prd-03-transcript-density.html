2 · What about reasoning and text between the steps?

Real runs interleave: think → call → “let me check the folder” → call → answer. D-3.1 as written bounded a group at any assistant text, which would shatter a chatty run into group · text · group · text and leave you worse off than today.

The projector already tells them apart, so this does not need a heuristic: model_delta and reasoning_summary_delta project to kind: "stream_delta", while final_response — and only that — projects to kind: "assistant_message". The group is terminated by the final response, not by text. Interim reasoning and narration are part of the work and live inside it, which is exactly what Codex’s Worked for 26s › swallows.

3 · What the summary line says

Elapsed comes from the shared duration formatter PRD-07 consolidates — max(updatedAt) − min(startedAt), the same synthesis ReasoningGroup already does for reasoning parts. A failed run does not collapse (D-3.5): you need the detail, so the group stays open on the failing step. A recovered one collapses like any success and carries a muted 1 retried — PRD-04 governs what that step looks like inside.

D-3.4 · one call gets no wrapper

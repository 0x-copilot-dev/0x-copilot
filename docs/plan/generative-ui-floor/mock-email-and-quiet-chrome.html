You watch it write. Red is removed, green is added, the caret is where it is still typing. Nothing sends until Approve — the same write gate every other connector write goes through.

Email is the sharpest case for the scope bug. "The object you approve is the object that is sent" is an abstraction for a priority field. Here it is literally the message. Today target_args can carry fields the diff never showed — on email that is a Cc you never saw. That is why the fix must be confining the payload to the edited fields, not merely listing more of it.

Nothing mints an email:// surface yet. The renderer matches on that URI and no producer emits one. A read produces a table of messages, and there is no gesture that turns "this row" into "compose a reply to it" — that handoff is the actual missing piece, not the renderer.
